# Project Name
MERN stack : Blog Website

## Description
This project is a full stack blog application which includes post CRUD, user authentication and text editor usage.

## Features
- ⚡ Full TypeScript support across frontend and backend
- 🔐 Secure authentication using JWT and bcrypt
- 🧠 Rich text editor powered by TipTap (headless & typed)
- 🎨 Responsive UI with Tailwind CSS
- 📦 Scalable backend with Express.js
- ☁️ Cloud database using MongoDB Atlas
- 🚀 Fast development workflow with Vite
- 🛠 Clean, maintainable, and modular codebase

## Tech Stack

### Frontend
- React
- Vite
- **TypeScript**
- Tailwind CSS
- TipTap (headless, fully typed editor)

### Backend
- Node.js
- Express.js
- **TypeScript**
- JWT (JSON Web Tokens)
- bcrypt

### Database
- MongoDB
